# Quick Notes App

A lightweight browser-based notes application built with HTML, CSS and JavaScript.

## Features
- Create, edit and delete notes
- Search notes by title or content
- Save notes in browser local storage
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add a title or note body and select **Add note**.

No server or package installation is required.

## Technologies
HTML5, CSS3, JavaScript, Browser Local Storage

## Note
Notes are stored in the current browser on the current device. They are not synced to an online account.
